# プライバシーポリシー

このプライバシーポリシーは、当サイト (recorder.appcloud.info) と Chrome 拡張機能 (Instant Tab Recorder) におけるユーザーデータの取り扱いについてご理解いただくことを目的としております。

ユーザーのプライバシー保護を第一に考え、不必要にデータを取得、保持、提供いたしません。

なお、本サービスの利用条件については [利用規約](TERMS_JA.md) をご確認ください。

## 利用目的

サービスの運営に必要な次の事項を目的とします。

- 品質改善
- 利用状況の把握

## 取得する情報

次の情報を取得、保持いたします。

- 拡張機能のインストール時にランダムに生成するユーザー ID (UUID v7)
- ブラウザの User-Agent
- 録画の設定情報および文字起こしの処理統計情報 (録画データや文字起こしテキスト本体は含まず)
  - 映像の解像度 (縦横のサイズ)
  - 映像のフォーマット (コーデック)
  - 映像のビットレート (データ量)
  - 文字起こしの処理時間、モデル種別、言語
  - その他設定項目

尚、取得する情報に個人を特定できる情報は含まれておりません。

## 取得しない情報

次に記載する情報は一切取得いたしません。

- IP アドレス
- 個人情報 (名前、住所、生年月日、メールアドレスなど)
- 録画データ
- 音声データおよび文字起こしデータ

## Cookie

直接的には使用しておりませんが、後述の外部サービスで利用されることがあります。

## 利用する外部サービスについて

利用する外部サービスについて以下に記載します。

収集される個人情報とその取り扱いポリシーについては各サービスのプライバシーポリシーをご参照ください。

- [Sentry](https://sentry.io/privacy/)
  - 目的: サービスの品質改善を目的として、クラッシュレポートの管理と利用状況の把握、フィードバックの受付のために導入しております
  - Chrome 拡張機能 (<= v1.2.0) の場合は Options Page => Privacy Settings => Bug Tracking からオプトアウトすることで、イベントの送信を無効化できます
  - Chrome 拡張機能 (>= v1.3.0) の場合は Options Page => Support Tab => Bug Tracking からオプトアウトすることで、イベントの送信を無効化できます
    - ただし、Sentry を利用している Feedback 機能はオプトアウトした状態では利用できません

- [Hugging Face](https://huggingface.co/privacy)
  - 目的: 文字起こし機能を利用する際に必要なモデルデータの取得に利用しております
  - Chrome 拡張機能 v1.8.0 で追加されました
  - Options Page => Settings からオプトインすることで、モデルデータのダウンロードが行われます
